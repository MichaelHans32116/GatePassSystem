# Employee Importer — Retired

This project is intentionally disabled. Its previous implementation was a
development-only HTTP/login test and was not a real employee importer.

Do not use it for account setup, password changes, web-login testing, or
employee synchronization. It now exits without reading or writing the database
and without making network requests.

For employee imports, use only the reviewed, documented IT data-loading process.
Never place real employee passwords, browser sessions, or server credentials in
this repository.
