Role-based UI logic

Same design language lahat, pero iba nav/actions.

Role	Main UI Purpose
Associate / Employee	Apply gate pass, view status, show QR
Driver-capable Associate	Apply gate pass with vehicle/driver fields if allowed
Immediate Superior	Approve/reject department requests
President	Approve special requests, especially company vehicle or manager-level requests
HR Head / PAS / Main HR	Final noting, monitoring, reports
Security Guard / Kiosk User	Scan QR, manual ID lookup, time-out/time-in
IT Admin / Developer	Manage users, roles, departments, vehicles, drivers, logs, settings

Important UI rule:

Users see only what their role needs.
Same layout, different navigation.
