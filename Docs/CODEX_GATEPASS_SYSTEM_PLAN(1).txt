Codex Plan: QR-Based Gate Pass and Vehicle Monitoring System

#Project Context

This project is a proposed web-based digital gate pass system for a company setting, specifically based on the current manual paper gate pass process used at Moriroku Philippines Inc.

The existing paper gate pass includes:
- Name of Associate
- Date Filed
- Destination
- Vehicle
- Purpose
- From Time
- To Time
- Approved By Immediate Superior
- Approved By President / Vice President
- Noted By PAS

The system is NOT GPS-based. Tracking is based only on approval status, QR scan events, time-out logs, time-in logs, and expected return time.

Core idea:
- If a request is approved but not scanned OUT, the associate is still inside the company.
- If a request is scanned OUT but not scanned IN, the associate is currently outside.
- If the current time is past the expected return time and there is still no IN scan, the request is overdue.
- If a company vehicle is used, the vehicle status changes based on the gate pass and scan events.

Suggested project title:
QR-Based Gate Pass Management System with Vehicle Availability and Return Tracking

---

#Main System Purpose

The system aims to digitize the manual company gate pass process by allowing associates to submit gate pass requests, enabling authorized officers to approve or note requests, allowing security guards to validate exits and returns using QR codes, and providing real-time monitoring of associate return status and company vehicle availability.

Main features:
- Gate pass request submission
- Approval workflow
- PAS/Admin noting or validation
- QR-based gate validation
- Time-out and time-in logging
- Currently outside monitoring
- Overdue return monitoring
- Company vehicle availability monitoring
- Reports and logs
- User and role management

---

#Core Logic Summary

Gate pass status depends on approval flow and scan events.

Vehicle status depends on reservation and scan events.

Overdue status depends on expected return time and missing time-in scan.

No GPS tracking is required.

Required data:
- Approved request
- QR scan OUT
- QR scan IN
- Expected return time
- Current time checker

#Request Statuses

Use these request statuses:

- DRAFT
- PENDING_SUPERIOR_APPROVAL
- PENDING_PRESIDENT_APPROVAL
- PENDING_PAS_NOTING
- APPROVED
- REJECTED
- CANCELLED
- EXPIRED
- OUTSIDE
- RETURNED
- OVERDUE

Status meaning:
- DRAFT: Request has not been submitted.
- PENDING_SUPERIOR_APPROVAL: Waiting for immediate superior.
- PENDING_PRESIDENT_APPROVAL: Waiting for president or vice president approval.
- PENDING_PAS_NOTING: Waiting for PAS/Admin validation.
- APPROVED: Request is approved and QR is active.
- REJECTED: Request was rejected by an approver.
- CANCELLED: Request was cancelled by requester or admin.
- EXPIRED: Approved request was not used before allowed time.
- OUTSIDE: Associate has been scanned OUT and has not returned.
- RETURNED: Associate has been scanned IN.
- OVERDUE: Associate is outside and expected return time has passed.

---

#Vehicle Statuses

Use these vehicle statuses:

- AVAILABLE
- RESERVED
- IN_USE
- RETURNED
- MAINTENANCE
- UNAVAILABLE
- OVERDUE

Status meaning:
- AVAILABLE: Vehicle can be selected for a gate pass.
- RESERVED: Vehicle is assigned to an approved or pending gate pass schedule.
- IN_USE: Vehicle left the company gate through a scanned OUT request.
- RETURNED: Vehicle returned through a scanned IN request.
- MAINTENANCE: Vehicle cannot be selected.
- UNAVAILABLE: Vehicle cannot be selected for another reason.
- OVERDUE: Vehicle is outside past expected return time.

#Gate Pass Request Creation Logic

```pseudo
FUNCTION createGatePassRequest(user, formData):
    REQUIRE user.role == ASSOCIATE

    VALIDATE formData:
        destination is required
        purpose is required
        from_time is required
        to_time is required
        from_time must be before to_time
        date_filed = current date automatically

    IF formData.vehicle_type == COMPANY_VEHICLE:
        vehicle = findVehicle(formData.vehicle_id)

        IF vehicle.status != AVAILABLE:
            RETURN "Vehicle is not available"

        IF vehicle has existing reservation overlapping from_time and to_time:
            RETURN "Vehicle already reserved for this time"

    request = new GatePassRequest
    request.requester_id = user.id
    request.destination = formData.destination
    request.purpose = formData.purpose
    request.vehicle_type = formData.vehicle_type
    request.vehicle_id = formData.vehicle_id optional
    request.from_time = formData.from_time
    request.to_time = formData.to_time
    request.date_filed = today
    request.status = PENDING_SUPERIOR_APPROVAL

    SAVE request

    IF company vehicle selected:
        create vehicle reservation
        reservation.status = RESERVED

    CREATE approval record:
        request_id = request.id
        approver_role = IMMEDIATE_SUPERIOR
        status = PENDING

    NOTIFY immediate superior

    RETURN "Gate pass request submitted"
```

#Immediate Superior Review Logic

```pseudo
FUNCTION superiorReview(superiorUser, requestId, decision, remarks):
    REQUIRE superiorUser.role == IMMEDIATE_SUPERIOR

    request = findRequest(requestId)

    IF request.status != PENDING_SUPERIOR_APPROVAL:
        RETURN "Request is not pending superior approval"

    IF superiorUser is not assigned superior of requester:
        RETURN "Not allowed to approve this request"

    IF decision == REJECT:
        request.status = REJECTED
        saveApproval(superiorUser, request, REJECTED, remarks)
        notifyRequester(request, "Rejected by immediate superior")
        RETURN

    IF decision == APPROVE:
        saveApproval(superiorUser, request, APPROVED, remarks)

        IF needsExecutiveApproval(request):
            request.status = PENDING_PRESIDENT_APPROVAL
            createNextApproval(request, PRESIDENT_OR_VP)
            notifyPresidentOrVP(request)

        ELSE:
            request.status = PENDING_PAS_NOTING
            createNextApproval(request, PAS)
            notifyPAS(request)

    SAVE request
```

```pseudo
FUNCTION executiveReview(executiveUser, requestId, decision, remarks):

        createNextApproval(request, PAS)
        notifyPAS(request)

    SAVE request
```

#PAS / HR Admin Noting Logic

```pseudo
FUNCTION pasNoteRequest(pasUser, requestId, decision, remarks):
    REQUIRE pasUser.role == PAS OR HR_ADMIN

    request = findRequest(requestId)

    IF request.status != PENDING_PAS_NOTING:
        RETURN "Request is not pending PAS noting"

    IF decision == REJECT:
        request.status = REJECTED
        saveApproval(pasUser, request, REJECTED, remarks)
        notifyRequester(request, "Request rejected by PAS/Admin")
        RETURN

    IF decision == NOTE_OR_VALIDATE:
        saveApproval(pasUser, request, NOTED, remarks)

        request.status = APPROVED
        request.qr_token = generateSecureQRToken()
        request.qr_expires_at = request.to_time

        IF request has company vehicle:
            reservation.status = RESERVED

        notifyRequester(request, "Gate pass approved. QR is now available.")
        notifySecurity(request, "New approved gate pass")

    SAVE request
```

#QR Generation Logic

The QR code should not contain full employee details.

The QR should contain only:
- gatepass_id
- qr_token

Use token hashing in database.

```pseudo
FUNCTION generateSecureQRToken():
    token = random secure string
    hashedToken = hash(token)
    save hashedToken in database
    RETURN token
```

#Security Scan Logic

```pseudo
FUNCTION scanGatePass(securityUser, qrData):
    REQUIRE securityUser.role == SECURITY

    request = findRequestByQR(qrData)

    IF request does not exist:
        RETURN "Invalid QR"

    IF request.status == REJECTED:
        RETURN "Rejected gate pass"

    IF request.status == CANCELLED:
        RETURN "Cancelled gate pass"

    IF current_time > request.to_time AND request.status != OUTSIDE:
        request.status = EXPIRED
        SAVE request
        RETURN "Gate pass expired"

    IF request.status == APPROVED:
        RETURN showScanResult(
            action = "TIME_OUT_ALLOWED",
            requestInfo
        )

    IF request.status == OUTSIDE:
        RETURN showScanResult(
            action = "TIME_IN_ALLOWED",
            requestInfo
        )

    IF request.status == RETURNED:
        RETURN "Already returned"

    IF request.status == OVERDUE:
        RETURN showScanResult(
            action = "TIME_IN_ALLOWED_BUT_OVERDUE",
            requestInfo
        )
```

#Record Time Out Logic

```pseudo
FUNCTION recordTimeOut(securityUser, requestId):
    REQUIRE securityUser.role == SECURITY

    request = findRequest(requestId)

    IF request.status != APPROVED:
        RETURN "Cannot time out this request"

    createGateLog:
        request_id = request.id
        guard_id = securityUser.id
        action = TIME_OUT
        scanned_at = current_time

    request.status = OUTSIDE
    request.actual_time_out = current_time

    IF request has company vehicle:
        vehicle.status = IN_USE
        reservation.status = IN_USE
        reservation.actual_time_out = current_time

    SAVE all

    RETURN "Time out recorded"
```

---

#Record Time In Logic

```pseudo
FUNCTION recordTimeIn(securityUser, requestId):
    REQUIRE securityUser.role == SECURITY

    request = findRequest(requestId)

    IF request.status != OUTSIDE AND request.status != OVERDUE:
        RETURN "Cannot time in this request"

    createGateLog:
        request_id = request.id
        guard_id = securityUser.id
        action = TIME_IN
        scanned_at = current_time

    request.status = RETURNED
    request.actual_time_in = current_time

    IF request has company vehicle:
        vehicle.status = AVAILABLE
        reservation.status = RETURNED
        reservation.actual_time_in = current_time

    SAVE all

    RETURN "Time in recorded"
```

#Overdue Monitoring Logic

This should run in a background job or scheduled task every few minutes.

```pseudo
FUNCTION checkOverdueRequests():
    requests = findAllRequestsWhereStatusIs(OUTSIDE)

    FOR EACH request IN requests:
        IF current_time > request.to_time:
            request.status = OVERDUE
            SAVE request

            notifyPAS(request, "Associate has not returned yet")
            notifySecurity(request, "Overdue gate pass")
            notifySuperior(request, "Your associate is overdue")

            IF request has company vehicle:
                reservation.status = OVERDUE
```

##Get Available Vehicles

```pseudo
FUNCTION getAvailableVehicles(from_time, to_time):
    vehicles = findVehiclesWhereStatusIs(AVAILABLE)

    availableList = []

    FOR EACH vehicle IN vehicles:
        reservation = findReservationOverlap(vehicle.id, from_time, to_time)

        IF reservation does not exist:
            availableList.add(vehicle)

    RETURN availableList
```

##Update Vehicle Status

```pseudo
FUNCTION updateVehicleStatus(vehicleId):
    vehicle = findVehicle(vehicleId)

    IF vehicle has active reservation with status IN_USE:
        vehicle.status = IN_USE

    ELSE IF vehicle has active reservation with status RESERVED:
        vehicle.status = RESERVED

    ELSE IF vehicle marked maintenance:
        vehicle.status = MAINTENANCE

    ELSE:
        vehicle.status = AVAILABLE

    SAVE vehicle
```
